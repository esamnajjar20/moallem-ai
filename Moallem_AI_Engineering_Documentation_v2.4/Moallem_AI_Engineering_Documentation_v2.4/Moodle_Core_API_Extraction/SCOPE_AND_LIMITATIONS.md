# Scope and limitations

هذا الاستخراج عام لـMoodle Core ولا يتطلب أي بيانات دخول أو صلاحيات مدير. يعتمد على كتالوج MoodleDocs التاريخي الموسوم 3.11 وعلى توثيق/ملاحظات إصدارات Moodle 5.1 و5.3؛ وتمت مراجعة ملاحظات Moodle 5.3.1 الصادر في 12 نوفمبر 2026، وهو أحدث patch release تحققنا منه حتى 15 نوفمبر 2026.

**لا يدّعي** أن السجلات هي القائمة الكاملة لكل الخدمات، أو أنها كلها قابلة للاستدعاء عبر Token، أو أن كل دالة تعمل مع دور teacher. كما لا يتضمن schema كاملًا للمدخلات والمخرجات لكل دالة.

لذلك فهناك مرحلتان مختلفتان:
1. **استخراج Moodle Core العام:** تم هنا.
2. **التحقق من تثبيت Moodle بعينه:** يتم فقط عند اختيار جهة/خادم مستهدف، ويشمل الإصدار، الخدمات الخارجية، الدوال المضافة للخدمة، البروتوكول، token permissions، capabilities، وتجربة staging.

لا يلزم أن يكون المطور مدير Moodle لإجراء المرحلة الأولى أو تطوير adapter عام. يلزم تعاون مسؤول النظام فقط عند تهيئة أو كشف خدمة على تثبيت Moodle فعلي أو تثبيت Local Plugin.
