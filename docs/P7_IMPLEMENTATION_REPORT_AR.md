# تقرير تنفيذ الجزء الرابع P7 — الموافقة والنشر

**الحالة: تنفيذ الأساس البرمجي جزئيًا؛ غير جاهز للنشر الحقيقي (PARTIAL / NOT READY).**

## ما تم تنفيذه

1. حفظ نسخة ثابتة ومرقمة من مسودة الاختبار، مع ربط محتواها وتقرير الجودة ومخطط البيانات والوجهة المحسومة من الخادم ببصمة SHA-256 موحدة.
2. جعل سجلات النسخ والموافقات غير قابلة للتعديل أو الحذف على مستوى PostgreSQL.
3. إضافة قرار موافقة/رفض مربوط بالمؤسسة والمهمة والعضوية ونسخة المسودة وبصمتها، مع انتهاء صلاحية ومفتاح idempotency.
4. إضافة API لقراءة Snapshot وتسجيل قرار الموافقة، مع إخضاع العمليات لسياسة الصلاحيات. السياسة الافتراضية `DenyAllPolicy` باقية كما هي حتى اعتماد DEC-027.
5. إضافة تجهيز Publish Intent داخل Repository مخصص للعامل، ولا يُنشأ إلا لمهمة `CREATE_QUIZ` مع موافقة صالحة ونسخة حالية.
6. إضافة سجل دائم لخطوات التأثير الخارجي ومفاتيح عمليات ثابتة، وتسجيل الحالات الملتبسة `UNKNOWN` ومصالحتها بدل إعادة الإنشاء عشوائيًا.
7. إضافة التحقق من نتيجة النشر قبل تسجيل `VERIFIED`، وربط النتيجة بمعرّف كائن Moodle وبصمة النسخة.
8. إضافة Migration رقم `c8f2a7d91e40` وفحص جاهزية يتأكد من وجود جداول P7 وعمود نتيجة المهمة.

## نتائج التحقق

- اختبارات P7 المركزة: **8 ناجحة**.
- كامل اختبارات Backend: **479 ناجحة، 46 متخطاة، واختبار واحد فاشل**.
- الاختبارات الـ46 المتخطاة تحتاج PostgreSQL حقيقيًا وتطبيق migrations؛ ومنها اختبار P7 المتكامل للموافقة ثم `UNKNOWN` ثم المصالحة والتحقق النهائي.
- الاختبار الفاشل `test_docs_disabled_in_production` تعذر بسبب عدم تثبيت `psycopg` في بيئة Python 3.13.5.
- `compileall`: ناجح.
- تحليل OpenAPI YAML: ناجح، ويحتوي 14 مسارًا.
- توليد SQL للترحيلات حتى `c8f2a7d91e40` دون اتصال: ناجح. لم يتم تطبيق Migration على قاعدة حقيقية.

## ما يمنع الإغلاق النهائي

- اعتماد DEC-027 لمصفوفة الصلاحيات وتكوين سياسة معتمدة؛ الافتراضي الحالي يمنع كل العمليات الحساسة.
- اعتماد DEC-043 وحجز الميزانية والتسوية الدائمة قبل أي تنفيذ AI فعلي.
- لا يوجد في هذا التسليم Moodle Write Adapter فعلي ولا إثبات قدرات إنشاء الاختبار على موقع Moodle محدد.
- يلزم ربط Worker handler بالـpreflight والموصل والقراءة الراجعة والتحقق، ثم اختباره على Moodle staging.
- يلزم تشغيل اختبارات PostgreSQL بعد تطبيق جميع الترحيلات، ثم التحقق من النسخ الاحتياطي والاستعادة وإجراء النشر.
- يلزم إعادة التحقق على Python 3.12 مع التبعيات المقفلة وتشغيل Ruff وMypy.

## حد الأمان

لم يتم تفعيل نشر حقيقي. `DenyAllPublishAuthorizer` هو الافتراضي، وAPI لا تملك مسارًا يرسل كتابة Moodle. لا يجوز اعتبار إنشاء Publish Intent أو تسجيل الموافقة دليلًا على نجاح النشر الخارجي.
